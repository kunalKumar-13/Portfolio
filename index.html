Page One · The Beat

Four systems shipped. All four still running.

A computer science undergraduate in Bengaluru has spent two years building software that remembers — and then kept it alive long after the demo.

By Kunal Kumar · Bengaluru · Frontend engineering intern, Emergent (YC S24)

Most student projects die at the demo. The four described in this issue did not. Recall, Aegis, PDFChat and Code-Guardian are deployed, reachable, and answering requests as this page is being read — every photograph printed here is a capture of the running thing, not a mockup.

The through-line is memory. A local-first engine that reconstructs unfinished work. A moderation pipeline that keeps the offending span, the reasoning and the full routing trace, so a decision can be opened up and appealed. An agent that answers from the document or refuses to answer at all.

The habit is the same each time: build the part that remembers why it did what it did, then hand it to somebody else.

Page Two — TechnologyMemory & continuity

Technology · Memory & Continuity

Engine hands back the thread you dropped

Recall watches what you were doing, scores what mattered, and returns the session in one keystroke — without sending any of it anywhere.

Work scatters. The tabs, the files, the half-finished chat — and between sessions the context evaporates. Recall is a local-first continuity engine: a browser extension and file watchers stream activity into a daemon that stores events, scores recovery and ranks what mattered, with semantic search across all of it.

A Qt launcher hands the thread back in a single keystroke. Nothing leaves the machine — no cloud, no telemetry, plain files that can be read and deleted by hand.

“Build the thing that remembers why it was built.”

Built solo, end to end: the extension, the daemon, the recovery interface, and the site that ships the macOS download.

Page Three — Trust & SafetyModeration

Technology · Trust & Safety

Moderation pipeline shows its working

Seven harm categories, a policy per platform, and a full trace kept for every call — so a decision can be appealed rather than merely announced.

A children's platform and an adult forum need different lines, and a black-box call cannot be appealed. Aegis scores content across seven harm categories, applies a per-platform policy of thresholds and custom rules, then routes by calibrated confidence — allow, review, or block.

Every decision keeps the offending span, the reasoning and the full routing trace, so the call can be opened up and audited after the fact rather than taken on trust.

“Scaling trust shouldn't mean scaling the moderation team.”

Built solo: the engine interface, the policy system, the review queue and the dashboard.

Page Four — TechnologyGrounding & refusal

Technology · Grounding & Refusal

Agent answers from the page, or not at all

A confident wrong answer is worse than no answer. PDFChat is built to say so.

Agents lie when retrieval gets messy. The failure is rarely dramatic — a plausible sentence, an invented figure, a citation to a page that says something else entirely.

PDFChat takes the opposite position. Answers are grounded in the document or the agent declines. Retrieval, citation and refusal are one path rather than three, so there is no route by which an ungrounded claim reaches the reader.

“Refusal is a feature, not a failure.”

Page Five — SecurityAutonomous review

Security · Autonomous Review

Review agent reads the repository, not the diff

Static scanners flag patterns. Code-Guardian is given an environment and asked to go and look.

Most security tooling matches patterns against a file and reports what it recognises. That catches the known shapes and misses the ones that only appear when two files are read together.

Code-Guardian is an agent with an environment rather than a scanner with a rule list. It navigates the repository, forms a view, and reports what it found and why it went looking — with the demo deployed and open.

“Not static scanning. An agent, in an environment.”

CorrectionsThe paper regrets the errors
  • Recall shipped an early build that scored recovery on recency alone. Recency is not relevance; a tab left open for six hours is not the thing you were doing. Scoring now weighs events, gaps and returns together.
  • Aegis at first returned a decision and a confidence figure and nothing else. A number is not an explanation and cannot be appealed. Decisions now carry the offending span, the reasoning and the full routing trace.
  • PDFChat initially answered every question put to it. The interesting cases are the ones where the document does not contain the answer, and answering them anyway was the bug. Refusal became a first-class path.
  • This newspaper once printed a contributions figure of its own invention when the GitHub feed was unreachable. It now says the feed is unreachable.
