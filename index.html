PDFChat indexes locally, rewrites queries against the relevant chunks, and every response either cites its pages or refuses clearly — with multilingual grounding that still treats the document as the only evidence.

Second brain — kunal_hq

An internship, college, three applications and a life, all carried in working memory. The fix wasn't discipline, it was a place. So I built one: a plain-text vault, an agent that reads and writes it, and a morning pulse at 8:23 that pulls in weather, calendar, GitHub and LeetCode — feeding one dashboard that always opens to exactly one thing.

Capture from any terminal: $ brain <thought> — two seconds, zero judgment, sorted later. The game layer earns XP only from real, verified data — never invented.
