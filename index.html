// because I kept losing my own unfinished work.

          

            
the problem
Work scatters. You start something, life interrupts, and the context — the tabs, the half-formed intent — evaporates between sessions. Tools remember files; nothing remembers where you actually were.

            
the build

// because agents lie when retrieval gets messy.

          

            
the problem
Support agents answer confidently even when retrieval hands them garbage — and a confident wrong answer costs more than no answer.

            
the build
A deterministic orchestration layer: explicit policy enforcement, safe tool gating and stateful multi-turn reasoning under adversarial inputs. Retrieval is a hybrid consensus — BM25 + TF-IDF + reranking with grounding diagnostics — plus multilingual injection defense, retrieval-poisoning defense, PII redaction and calibrated confidence. When grounding is weak it refuses, the same way every time.
↳ built and tuned the full retrieval → refusal path.

// because scaling trust shouldn't mean scaling the moderation team.

          

            
the problem
Platforms drown in user content. One-size-fits-all moderation misroutes everything — a kids' platform and an adult forum need different lines — and black-box decisions are impossible to audit or appeal.

            
the build
A multi-stage pipeline: an engine scores content across 7 harm categories (Gemini, with a deterministic local fallback that always works), a per-platform policy applies thresholds, weights and custom rules, and confidence routes each item — allow, human review, or block. Every decision is explainable: the offending span, the category, the reasoning, the full routing trace.
↳ solo — engine interface, policy system, review queue, dashboard.

          

          

            
01classify — 7 categories, 0–1 confidence, offending spans

            
02apply policy — per-platform thresholds, toggles, custom rules

            
03route — ALLOW · REVIEW · BLOCK, by calibrated confidence

            
04review — priority queue for humans; verdicts feed back as audit
